# Ashes Stack

Ashes Stack is the official home of Ashes products, services, and creator tools.

## Products

- Ashes Assets — discover, buy, and download game-ready 3D assets
- Ashes AI — image-to-3D generation tools
- Ashes Brain — AI productivity tools

## Development

This project uses React, TypeScript, Vite, and Vercel serverless functions.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Production

Website: https://www.ashesstack.cloud
