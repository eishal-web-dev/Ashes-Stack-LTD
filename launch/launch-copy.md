Stop repeating project context to ChatGPT, Claude and other AI tools. Ashes Brain stores your project goals, decisions, memories and handoffs once, then lets supported AI clients work from the same shared context.

### First comment
I kept running into the same annoying problem: every time I switched AI tools, I had to explain the project again.

Ashes Brain is my attempt to remove that repetition. You create a project once, connect supported AI clients through MCP, and the same project memory can follow you between them.

The idea is deliberately simple: **Tell one. All of them know.**

The first live version already has Brain-only accounts, OAuth, shared project memory, read/write MCP tools, and public project sharing. I’d love feedback on where cross-AI handoffs still feel clunky.

## Reddit — r/ClaudeAI / r/ChatGPTCoding style
### Title
I built a shared project memory so I can switch between ChatGPT and Claude without re-explaining everything

### Body
I use multiple AI tools on the same projects and the biggest friction for me was context fragmentation. ChatGPT would know one set of decisions, Claude another, and I’d keep copying summaries between them.

I built a small product called **Ashes Brain** around a shared project-memory layer. It exposes a remote MCP server with OAuth. A connected AI can list projects, retrieve context, search saved memory, save durable decisions, and leave a handoff for the next AI.

The goal is not to replace ChatGPT or Claude. It’s to keep using the subscriptions you already have while giving supported tools one shared project context.

I’ve got the backend and OAuth flow working and I’m looking for feedback on the UX, especially how much should be automatic versus explicitly saved.

Demo/product: https://www.ashesstack.cloud/workspace
